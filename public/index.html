游戏连接信息

在游戏的自定义 OpenAI 接口中填写以上三项；游戏传入任意模型名都会被映射到下方上游模型。

上游 Provider

开启后执行日志可显示每轮精确 token 总数；个别游戏端可能不兼容额外的用量数据包。关闭时按字符估算。

请求超时同时作为流式空闲超时，慢速 Provider（如 GLM）可调大；若游戏端自己先超时，调这里无效。

记忆设置

外置设定提示词

优先级：本轮 JSON 输出格式（不可更改）> 全局/个人提示词 > 长期记忆 > 游戏设定（含角色设定、世界观、时间地点场景）。可在「NPC 记忆」页为某个 NPC 追加个人提示词，或让它不叠加全局。

多 NPC 共演 实验性 额外 token 消耗

开启后，玩家可以用括号把另一位 NPC 拉进当前对话（如「（章籽梦走进来）章籽梦，你怎么看」）。配角会单独请求上游，主角只能看到配角的公开台词，不会拿到配角的设定与记忆。每轮最多 2 次发言调用；关闭时对原有对话零影响。
注意：只有在该 NPC 详情里勾选「允许作为配角参与共演」的 NPC 才会被邀请；默认全部关闭。调试也可直接发 /invite 名字、/remove 名字。

关闭时：配角进出场只认显式指令——/invite 名字、/add 名字 请人入场， /leave 名字、/remove 名字 请人离场；台词与括号里的动作只当叙事事实， 不会改变在场状态（无来往超过“超时清场”时长会自动离场）。
开启时：额外允许按台词自动调度 （如「（章籽梦走进来）」入场、「（章籽梦离开了）」离场、直呼其名可自动入场），更省事，但措辞可能被误判。

请求重写 实验性 额外 token 消耗

启用后，每次 NPC 对话会先额外调用一次上游模型，逐条改写游戏下发的设定类 system 模块（世界观、角色设定、场景、任务、输出格式等，真实请求通常有多条），删除或改写其中与本工具外置提示词／长期记忆冲突的部分，再生成回复。游戏已结算的事实模块（【相关经历】、【人物关系】、【任务接取】、【任务交付】、【好感变化】、【赠出礼物】 等）原样透传，不参与重写；## 输出格式 里的 JSON 结构始终逐字保留。首字延迟与 token 消耗都会明显增加；重写失败或单个模块校验不通过时，该模块自动回退原文。

语音朗读 实验性

离线合成，免费、无需 Key、不联网；声音由本窗口播放，窗口最小化也能听到。 开启后每条新到的 NPC 回复会自动朗读；关闭时完全不会合成，也不会启动任何系统进程。 历史回复不补播——可在「执行日志」里点每条记录上的 ▶ 手动朗读。

音色

引擎决定可选的声音：Windows 内置语音即时出声（首音约 0.5 秒）但偏机械； Kokoro 神经语音接近真人，但合成比播放慢（6 秒台词约需 8 秒）。
